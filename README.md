# Custom Shirt Studio — Version 1 Prototype

This is a working, mobile-friendly prototype for a custom shirt ordering app.

## Included

- Product selection
- Shirt color selection
- Front and back design areas
- Upload customer artwork
- Add custom text
- Change font and text color
- Drag artwork/text
- Resize and rotate selected elements
- Duplicate and delete elements
- Adult size quantities
- Automatic bulk pricing
- Front and back order previews
- Customer approval checkbox
- Demo order creation
- Local design saving

## How to open it

1. Unzip the folder.
2. Open `index.html` in Chrome, Safari, or Edge.
3. No installation is required.

For the best results while developing, run it with a simple local web server:

### Windows
Open Command Prompt in the folder and run:

    python -m http.server 8000

Then open:

    http://localhost:8000
