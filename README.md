# Custom Shirt Platform V5 — Phase 1, 2, and 3 Prototype

This package combines the three requested phases into one upload.

## Phase 1 — Customer Ordering
- Product catalog
- Front, back, and left-chest designer
- Artwork upload
- Text tools
- Quantity pricing
- Checkout form
- Order dashboard
- Mobile installation

## Phase 2 — Virtual Try-On
- Customer photo upload
- Shirt or hoodie overlay
- Shirt color selection
- Position and size controls
- Design upload
- Downloadable try-on preview

The included try-on is a local visual compositor. True body-aware AI fitting requires a paid or self-hosted AI model and a secure backend.

## Phase 3 — Business Tools
- Orders
- Customers count
- Coupons
- Inventory alerts
- Order statuses
- JSON exports
- Fulfillment configuration
- Stripe and Supabase configuration placeholders

## Real product images

The catalog can contain real blank models such as Gildan 5000, Bella+Canvas 3001, and Comfort Colors 1717, but manufacturer or supplier images should only be uploaded when you have permission to use them. This package keeps generic product art so the public website does not misuse copyrighted supplier photos.

## Secure integrations still require your accounts

These cannot be safely activated in public GitHub Pages files:
- Stripe, Apple Pay, and Google Pay
- Shared cloud order database
- Customer accounts
- Email and SMS
- Shipping labels and live carrier rates
- True AI body-aware try-on
- Apple App Store and Google Play publishing

Use `config.js` for business branding and integration settings.
