# Custom Shirt Platform V10 — Full Designer Upgrade

New features:
- Mouse and touch dragging
- Corner resize handles
- Rotation handle
- Unlimited text layers
- 12 font choices
- Bold, italic, underline
- Text color, outline, shadow, spacing, and curve
- Edit existing text
- Front, back, left/right chest, and both sleeves
- Layers panel
- Lock, hide, flip, reorder, duplicate, and delete
- Permanent Home button
- Updated review previews
- Fresh offline cache

Install:
1. Extract the ZIP.
2. Copy everything inside.
3. Paste into Documents\GitHub\custom-shirt-studio.
4. Replace files.
5. Commit with: Version 10 Full Designer
6. Push origin.
7. Wait for GitHub Pages deployment.
8. Refresh with Ctrl + Shift + R.

This remains a browser prototype. Secure payments, shared accounts, live inventory, and cloud orders require a backend.
